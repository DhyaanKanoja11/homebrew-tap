# Homebrew Tap for Lantern

Official Homebrew Tap for [Lantern](https://github.com/DhyaanKanoja11/Lantern), a local-first security CLI for developers explaining configuration causality behind exposed services.

## Installation

`ash
brew tap DhyaanKanoja11/tap
brew install lantern
`

Or install in a single command:

`ash
brew install DhyaanKanoja11/tap/lantern
`

## Documentation

See the [official repository](https://github.com/DhyaanKanoja11/Lantern) for full documentation, commands, and security model.
